# Contributing

Thank you for helping keep the Agent Infra Projects index useful and accurate. Pull requests are welcome for three kinds of changes:

- adding a project;
- updating an existing project; or
- removing a project that is no longer relevant or is materially inaccurate.

## Submission process

1. Fork the repository.
2. Create a focused branch from `main`.
3. Edit the **Project index** table in `README.md`.
4. Open a pull request using the project-index template.

## Entry guidelines

Each entry needs a project name, a clear one-line description, specific focus areas, and an official website or source repository when available.

- Use primary sources: the project website, source repository, or official documentation.
- Keep the description factual and neutral; avoid promotional claims.
- Use short, specific focus labels so people can scan and compare entries.
- Do not add duplicate listings. Update an existing entry instead.
- For removals, say why the project should leave the index and link to an archive, shutdown, or other relevant source when possible.

## Review

Maintainers review scope, accuracy, source links, wording, and duplicates. They may request edits to keep the index focused and trustworthy.
